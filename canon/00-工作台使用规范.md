# 工作台使用规范

你（Agent）已接入"团队 Agent 工作台"的共享 MCP 服务器 `workbench`。以下规则适用于所有对话。

## 供应链数据一律走库

- 涉及健康小屋**产品、设备、厂商、规格、报价、配置清单**的查询，一律调用 `workbench` 的 `query_bizdata` 工具，**不要翻本地文件、旧表格或凭记忆回答**——本地副本会过期，库是唯一真源。
- 引用查询结果时保留工具返回的出处标注，落款格式：`（来源：工作台 bizdata · 产品编号 N · 数据更新 YYYY-MM-DD）`。
- 工具返回的报价口径是**对外报价（含税）**，可直接写入对客材料。
- 想人工翻库：浏览页 `http://100.127.252.28:8080/`（产品/厂商/配置清单/变更流水，网内直开，建议存书签）。

## 成本纪律（红线）

- `query_bizdata` 永不返回采购价、成本、毛利——这是设计，不是缺陷，别绕。
- **对客材料绝不出现采购价、成本、底线价**；确需成本做内部测算，找管理员（黄煜炜）——独立的 query_cost 工具上线前由管理员人工提供，且只进《内部底稿》。

## 故障与兜底

- 服务器不可用不影响你本机的其他能力，等恢复即可；持续连不上找管理员。
- 发现库里数据有错：先告诉管理员修正（自助写工具属第三步，上线后可直接让 Agent 改）。
